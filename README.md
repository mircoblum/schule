# Schule

Lernaufgaben und Quizze zum Üben, als einzelne Webseiten über GitHub Pages.

## Aufbau

```
Lernaufgaben/
  Klasse 5/
    Erdkunde/
      atlas-check/   Quiz „Orientierung im Atlas“
```

Jede Lernaufgabe liegt in einem eigenen Ordner unter `Lernaufgaben/<Klasse>/<Fach>/` und hat eine `index.html`.
