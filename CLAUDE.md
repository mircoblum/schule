# Repository „schule“

Sammlung von Lernaufgaben und Quizzen, veröffentlicht über GitHub Pages unter https://mircoblum.github.io/schule/.

## Konventionen
- Neue Lernaufgaben kommen nach `Lernaufgaben/Klasse <n>/<Fach>/<kurzer-name>/index.html`.
- Jede Lernaufgabe ist eine eigenständige HTML-Seite (inline CSS/JS, Bibliotheken nur von CDNs), die ohne Anmeldung auf dem iPhone läuft.
- Für das iPhone: `apple-touch-icon.png` (180×180) und die `apple-mobile-web-app-*`-Metatags in den Ordner bzw. Kopf legen.
- Sprache der Inhalte: Deutsch.
- Neue Lernaufgaben in die Tabelle in `README.md` eintragen (Links mit `%20` für Leerzeichen).
